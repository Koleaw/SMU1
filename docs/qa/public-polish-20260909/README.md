## Поиск и движение

Локальный статический индекс содержит **99 уникальных опубликованных записей**: 68 изделий, 22 категории/каталога, пять направлений и четыре объекта. Индекс строится из текущих данных; черновики, неопубликованные родительские категории, дубли, админка и Design Lab исключены. Запросы не отправляются сторонним сервисам, не пишутся в URL/хранилище и исключены из записи существующим Webvisor. Модуль и индекс загружаются при первом открытии поиска.

Проверены точные названия всех записей, русские окончания, ё/е, лавочка/скамейка/скамья, отсутствие совпадений, загрузка/ошибка/повтор, клавиатура и возврат фокуса. Поиск проверен также на отдельной реальной сборке с `BASE_PATH=/`, во всех трёх движках.

Видео разделяет автоматическое и явное воспроизведение; повторно выбирает источник после изменения размера окна, сохраняет паузу, учитывает reduced-motion/save-data, показывает постер и возможность повтора при ошибке. Сохранены исходные MP4; при ошибке декодирования desktop используется имеющийся Baseline-вариант. Проверено продвижение `currentTime`, а не только наличие video-элемента.

Появление изображений связано с готовностью декодирования; ошибка и таймаут оставляют доступный контент. Пропущенные при резкой прокрутке заголовки больше не удерживают секцию скрытой. Проверены последовательные переходы, Back/Forward, повторное посещение, reduced-motion и отсутствие JavaScript.

В полном выпускном прогоне обнаружено преждевременное завершение первичного появления при обычном событии NetworkInformation `change`: изменение RTT без смены режима отменяло entrance ещё до start. Причина воспроизведена отдельно; теперь обработчик сравнивает режим, а реальные переключения reduced-motion/save-data по-прежнему немедленно завершают движение. Регрессия добавлена в существующий H2 gate. Точные типографические ожидания этого gate обновлены под принятую композицию категорий, юридической страницы и вакансии; допуск 0,25 px сохранён.

Статический контракт, поиск после pruning и 14/14 проверок test/production isolation пройдены. Полный обязательный выпускной набор H6 остаётся в существующем GitHub Actions: тесты сохранённого редактора, exact SSG, паспорта маршрутов, публичные действия, приватность медиа, восстановление и сверка доказательств. Устаревшие утверждения о старом тексте и Google Fonts обновлены под согласованное поведение без удаления проверок схемы и связей. В тесте image-ready исправлен противоречивый глобальный Save-Data fixture; проверки задержки, таймаута, ошибки и видимости сохранены.

Выпускной паспорт выявил два дополнительных источника расхождений public/editor. Пустые редакторские слоты двух категорий на странице ограждений теперь используют существующий overlay-механизм H6, сохраняя публичную композицию и привязки полей. Для начертания 500 проверены фактические платформенные шрифты через CDP: при одинаковом CSS публичный текст иногда использовал Segoe UI Semibold вместо Manrope Medium, меняя ширину `76ch` и число строк. Ранняя загрузка этого начертания устраняет причину без увеличения набора шрифтов и без изменения геометрических допусков.

В диагностике исправлена гонка немедленного перенаправления: повторяется только внутренняя проверка готовности документа после подтверждённой ошибки замены контекста CDP, с общим ограничением времени. Обычные действия и ошибки JavaScript не повторяются и не подавляются. При аварии паспорт сохраняет неполный диагностический JSON и печатает конкретные ошибки маршрутов. Проверенные H5-производные теперь сохраняются в существующий CI-кэш сразу после успешной проверки бюджетов, чтобы поздняя ошибка другого этапа не уничтожала результат холодной генерации; все выпускные проверки сохранены.

Контрольный просмотр после стабилизации шрифтов выявил два узких исключения: длинное слово в мобильном CTA металлоконструкций выходило за край, а названия объектов получали неудачные автоматические переносы. Масштаб этих заголовков уточнён только на телефонах; текст сохранён, геометрические допуски QA не изменены. Локальный exact SSG запускается с `TEST_SITE_URL=https://koleaw.github.io` и отдельным `BASE_PATH=/SMU1`. Старый сервер редактора на порту 4322 остановлен: он удерживал native-компилятор, мешая Windows удалить hardlink из временного workspace. Изменений механизма H6 для этого не потребовалось.

Побайтная диагностика exact SSG выявила преобразование LF в CRLF для двух raw `?url` модулей поиска при новом Windows checkout. `.gitattributes` закрепляет LF только для этих файлов; сравнение HTML не нормализуется и не ослабляется. Свежая полная и независимая targeted сборки теперь проходят штатную строгую проверку: 28 маршрутов, 27 вариантов рендера, 4612 файлов H5.

Финальный локальный паспорт полностью прошёл 222/222 сочетания 111 URL и двух размеров, плюс оба неизвестных адреса; событий console/network и утечек редактора нет. Отдельные проверки интерфейса — 17/17, движения — 175/175, статического контракта — 38/38, H5 — 22/22 до и после pruning, поиска — 99 записей. Текущие максимумы gzip на публичный маршрут: HTML 24 512 байт, JS 24 983 байта, CSS 76 493 байта; четыре шрифта — 91 140 байт. Подготовленный артефакт — 414 042 432 байта. Поздний тест публичных действий содержал прежнее требование скрывать кнопку видео при reduced-motion/saveData. Контракт исправлен под разделение автоматического и явного запуска: до клика нет источника и запросов видео, доступная кнопка запускает настоящее продвижение `currentTime`, затем пауза останавливает его. Проверки редактора и источники публичного видео не изменялись.

## Реальные ограничения

Физический компьютер Windows 8, физические мобильные устройства и установленный Chrome 109 недоступны. Подмена User-Agent не использовалась. Проверены актуальные движки, сборка JS ограничена целью Chrome 109; это не равно запуску в самом Chrome 109. Для окончательного закрытия жалобы владельца нужен номер браузера и короткая проверка на том компьютере. Админка, юридическое оформление будущего сбора заявок и платный хостинг остаются следующими этапами.
