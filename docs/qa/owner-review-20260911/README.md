## Контент, редактор и ограничения

Вакансии редактируются в **«Все материалы» → «Страницы сайта» → «Вакансия»**. «Должность» задаёт название, «Краткое описание» — вводный рассказ с абзацами, «Обязанности», «Требования» и «Условия» — отдельные списки, «Зарплата», «Город» и «Занятость» — сведения рядом с названием. «Сохранить на компьютере» сохраняет локально, «Открыть локальную страницу» позволяет проверить результат; публикация остаётся отдельным действием. Подробный протокол и контрольная сумма неизменённой вакансии — [vacancies-map.md](vacancies-map.md).

Настоящий медведь: `/uploads/chatgpt-image-5-2026-21-56-34-1783277800820.png`. Навес: `/uploads/chatgpt-image-23-2026-11-43-06-1779555009138.png`. Обе плитки используют `homeImage` соответствующего направления, поэтому фотографию можно заменить через существующий редактор. Тексты и исходные изображения ради композиции не подменялись; переносы настроек кадрирования перечислены в [media.md](media.md).

Карта работает через сохранённый конструктор Яндекса. В имеющейся конфигурации отсутствует ключ JS API для поддерживаемой тёмной картографической темы и собственной метки СМУ-1. Поэтому тёмным оформлен внешний блок, а рабочая схема, метка и атрибуция провайдера сохранены. Междоменный iframe нельзя перекрасить внутренними стилями родительской страницы. Некоторые внутренние HTTP-ошибки iframe могут сообщать браузеру `load`; их нельзя достоверно распознать снаружи. Ошибка конструктора, событие `error` iframe и таймаут обрабатываются. Полное объяснение — [vacancies-map.md](vacancies-map.md).
