## Где редактировать вакансии

Откройте **«Все материалы» → «Страницы сайта» → «Вакансия»** и выберите запись.

| Что нужно изменить | Поле редактора |
| --- | --- |
| Название вакансии | «Должность» |
| Рассказ о работе, несколько абзацев | «Краткое описание» — название поля не ограничивает его короткой строкой |
| Списки, по одному пункту на строку | «Обязанности», «Требования», «Условия» |
| Сведения рядом с названием | «Зарплата», «Город», «Занятость» |
| Видимость записи | «Показывать вакансию» |
| Текст страницы со списком вакансий | Настройки страницы «Вакансии» |

После изменения используйте **«Сохранить на компьютере»**, затем **«Открыть локальную страницу»**. Публикация — отдельное действие. Описание выводится безопасными абзацами обычного текста; новое дублирующее поле не понадобилось. Пустое необязательное поле не создаёт пустую секцию. Протокол изолированного редактирования — [vacancies-map.md](vacancies-map.md).

## Объём личного просмотра и ограничения

Автоматический обход всех 111 маршрутов не назван личным визуальным просмотром каждого маршрута. Ранее локально просмотрены 78 изменённых каталожных маршрутов (234 кадра), 42 сочетания ширины/маршрута для 12 характерных страниц и 54 нижние секции пяти направлений и контактов. Проверены также архив вакансий с одним элементом и пустой архив, необычные фото, длинные тексты, fullscreen, первое открытие и темы favicon. Эти ранние проходы предшествовали отдельным завершающим исправлениям взаимодействий; актуальную опубликованную проверку описывает раздел выше.

Локальные ширины включали 1366, 1024, 768, 390 и 320 px. Настоящее увеличение Chrome до 200% проверено на главной, навесах, «Волне» и контактах через `tabs.getZoom() = 2`, `innerWidth = 683`, DPR 2, без переполнения. Реальное старое устройство не использовалось; эмуляция и замедление CPU не выдаются за такую проверку. Native Back/Forward проверены, но `BFCache persisted=true` не наблюдался. В установленном Windows WebKit обычный Tab пропускает часть ссылок даже на простом HTML; полный охват hero-ссылок этим способом не заявляется, кнопки/стрелки/возврат фокуса проверены отдельно.

**Карта:** в сохранённом подключении конструктора нет ключа JS API для поддерживаемой тёмной картографической темы и собственного маркера СМУ‑1. Сейчас автоматически загружается рабочая карта с провайдерской отметкой, подписями и атрибуцией; фирменно оформлен внешний блок. Тёмный слой и фирменная метка РМК были просмотрены на референсе, но внутренний DOM междоменного iframe нельзя оформить стилями сайта. Для такой кастомизации потребуется ключ и поддерживаемое API-подключение. Некоторые внутренние HTTP-ошибки iframe сопровождаются событием `load` и не распознаются достоверно снаружи; адрес, внешняя ссылка и маршрут остаются доступны.
