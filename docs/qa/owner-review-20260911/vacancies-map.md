# Вакансии и карта: проверка замечаний 9–10

## Где редактировать вакансии

В локальном редакторе откройте **«Все материалы» → «Страницы сайта»**, затем нужную запись в группе **«Вакансия»**.

| Блок на сайте | Поле в редакторе |
| --- | --- |
| Название вакансии | «Должность» |
| Вводный рассказ о работе | «Краткое описание»: можно написать несколько абзацев; переносы строк сохраняются на подробной странице |
| Обязанности | «Обязанности», один пункт на строку |
| Требования | «Требования», один пункт на строку |
| Условия | «Условия», один пункт на строку |
| Оплата | «Зарплата» |
| Место работы | «Город» |
| Формат работы | «Занятость» |

Существующего поля описания достаточно: отдельное дублирующее поле не добавлено. Текст выводится безопасно, HTML не исполняется. Общие заголовки разделов и тексты архива доступны в настройках сайта, в группе «Вакансии».

После изменения нажмите **«Сохранить на компьютере»**, затем **«Открыть локальную страницу»**. Публикация на тестовый сайт остаётся отдельным действием. Переключатель «Показывать вакансию» управляет её присутствием на сайте.

## Что изменилось в карте и что ограничено подключением

Карта автоматически загружается в пределах 200 px от окна. Место под неё зарезервировано заранее. Внешняя панель оформлена тёмным цветом, добавлено действие **«Построить маршрут»** к адресу **ул. Промышленная, 17, Курган**. Подписи и атрибуция Яндекса сохранены. Колесо мыши не меняет масштаб автоматически появившейся карты. Готовность определяется загрузкой документа iframe, а не его вставкой в страницу; при ошибке или ожидании дольше 15 секунд доступен повтор.

В текущей конфигурации используется сохранённая карта конструктора, без ключа Яндекс JS API. Поэтому сохранены её рабочая картографическая схема и метка. Тёмная тема самого картографического слоя и знак СМУ-1 вместо геомаркера требуют подключения поддерживаемого JS API с ключом; стили родительской страницы не могут изменить внутренний DOM междоменного iframe. Слой не перекрашен фильтрами. Референс: [страница контактов РМК](https://rmk-group.ru/contacts/); поддерживаемая настройка темы описана в [документации Яндекс API](https://yandex.com/maps-api/docs/js-api/object/layers/YMapDefaultSchemeLayer.html).

Есть также ограничение браузера: некоторые сетевые/HTTP-ошибки внутри междоменного iframe могут сопровождаться событием `load` вместо `error`. Родительская страница не может достоверно отличить такой ответ от успешного документа. Ошибки конструктора, событие ошибки iframe и зависшую загрузку компонент обрабатывает; адрес и внешние ссылки остаются доступны независимо от карты.
