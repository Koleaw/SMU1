# Отклоненные и опасные паттерны для СМУ-1

Отклонение относится к будущей концепции СМУ-1, а не является оценкой качества референсного сайта. Прием может быть уместен для Foster, Vestre, mmcité, Skanska или Linear из-за другой репутации, базы контента и модели продажи.

## Нельзя использовать в текущем контексте

| Паттерн | Доказательный источник | Почему нельзя переносить | Допустимая замена |
|---|---|---|---|
| Hamburger-only как единственная desktop-навигация | Foster [`home-desktop-viewport.png`](screenshots/foster/home-desktop-viewport.png) | Скрывает каталог, услуги, объекты и контакт — четыре разных сценария СМУ-1 | Видимые ключевые маршруты + More для вторичного |
| Hero/услуга/объект без коммерческого CTA | Foster project, mmcité hero, Skanska Construction | Известные бренды продают репутацией; СМУ-1 должен загружать сварочный цех | 1–2 действия: расчет/обсуждение задачи |
| Сплошная темная тема для каталога и forms | Linear full site | Ухудшает чтение specs, price, delivery и form fields; физические товары требуют ясных материалов | Dark hero/band, светлые functional surfaces |
| Автовидео как обязательный hero на всех страницах и devices | Foster/Vestre/Skanska; Plan Linear | Вес, трафик, accessibility, отсутствие сильного ролика | Статичный poster/фото; video только при доказанной ценности |
| Minimal project-card как product-card | Foster/Skanska cards | У товара нужны параметры, price status и варианты | Отдельный компонент product card |
| Фасеты уровня `466/865 projects` при четырех опубликованных объектах | Foster/Skanska Projects | Создадут пустые результаты и ложное ощущение масштаба | Tags или простой filter по направлению |
| Полноэкранный mega-menu высотой `729px` без сокращения | mmcité Products menu | Трудно обслуживать, перегружает mobile и дублирует утвержденное дерево | Компактное 2-level меню с приоритетными категориями |
| Горизонтальная карусель для основного списка категорий/specs | Mobile референсов | Скрывает объем и требует неочевидного жеста | Вертикальная/двухколоночная taxonomy; carousel только related |
| Скрытие ключевых B2B-фактов целиком в accordion | Foster project facts | Муниципальный/коммерческий заказчик может не увидеть scope, сроки и роль | Основные факты открыты, вторичные details сворачиваются |
| Цена только после login | Vestre STOOP | Противоречит честной модели `от`/`по запросу` и добавляет барьер | Публичный price status + факторы расчета |
| Имитация масштаба неподтвержденными цифрами, клиентами или географией | Foster/Skanska trust model | Нарушает MASTER_SPEC и снижает доверие | Только датированные проверяемые факты СМУ-1 |
| Копирование текстов, CSS, HTML, изображений или фирменной графики референсов | Все сайты | Запрещено исходным ТЗ и не создает собственную систему | Перенос абстрактного принципа на контент СМУ-1 |

## Условно отклонены до появления предпосылок

| Решение | Что должно появиться до возврата к идее |
|---|---|
| Video hero | профессиональный ролик, poster, права, несколько форматов, pause, reduced-motion, performance budget |
| 3D/BIM viewer | актуальные модели, владелец обновлений, lazy loading и mobile fallback |
| Map объектов | достаточная география, проверенные координаты и практическая задача поиска |
| Full faceted filtering | достаточное число товаров/объектов и заполненные filter fields |
| Sticky configuration bar | реальные варианты/цены, состояние выбора, проверка перекрытия mobile и accessibility |
| Темная главная как у Foster/Linear | единый качественный фотобанк и подтвержденный контраст реальных изделий |
| Длинная editorial product page >10 000px | готовые specs, документы, фото, понятная навигация и progressive disclosure |

## Красиво, но может мешать продаже

| Прием | Визуальный плюс | Коммерческий минус | Решение |
|---|---|---|---|
| Полноэкранный hero без следующего шага | Максимальный масштаб фотографии | Пользователь не видит каталог/расчет | Оставить media, добавить короткие scenario CTA |
| Очень крупный headline на полэкрана | Редакционная уверенность | Длинная кириллица закрывает объект и переносится на 4–6 строк | Ограничить width/scale, тестировать реальные названия |
| Асимметричная grid всех cards | Живой ритм | Сложнее сравнить однотипные товары | Асимметрия для featured story, регулярность для выбора |
| Минимальные подписи под предметным фото | Чистота каталога | Нет материала, размера, установки и price status | Добавить небольшой фиксированный набор данных |
| Low-contrast gray labels Linear | Тонкая иерархия | Критичные specs/contacts могут стать нечитаемыми | Повысить контраст коммерческих и технических данных |
| Scroll-dependent blur/reveal Vestre | Эффект появления | Хрупкий рендер, screenshot/SEO/performance риск | Нативный lazy load без скрытия уже загруженного контента |
| Horizontal partial-next cards | Подсказывает продолжение | Основные варианты остаются за жестом | Применять только к related content |
| Long story до CTA | Создает бренд и погружение | Лид не находит быстрый расчет | Первый CTA после вводных данных, повтор после proof |
| Большой footer-набор ссылок Linear | Показывает зрелость продукта | Не соответствует реальному объему СМУ-1 | Короткий footer по основным сценариям и реквизитам |

## Риски производительности

Следующие сочетания следует считать отклоненными, пока не установлен budget:

- несколько autoplay videos на одной странице;
- десятки full-resolution images без responsive `srcset`/lazy loading;
- reveal, который удерживает blur/opacity на off-screen media;
- WebGL/3D/map в initial load;
- сотни Web Animations для decorative motion;
- third-party readers и embeds в критическом пути;
- одновременная загрузка gallery, related products и references ниже fold.

## Риски дорогого контента

Нельзя утверждать концепцию, основанную на Foster/Vestre/Skanska-scale media, до фото-аудита. Если качественных кадров недостаточно, следует выбрать более плотную информационную композицию, а не заменять фото stock, blur, gradient или декоративными placeholders.

## Итог

Главный отказ пилота: не переносить видимую «премиальность» отдельно от информационной модели и контента. Для СМУ-1 чистота допустима только вместе с ценой/статусом, характеристиками, доказательствами и быстрым контактом.
